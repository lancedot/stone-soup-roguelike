# 面包小队小体量设计

## 目标

第一版是一个 10 分钟以内的轻量传统 roguelike。保留随机地图、回合制、撞怪攻击、技能冷却、道具构筑和永久死亡，不迁 Godot，不扩展复杂系统。

## 角色与技能

| 职业 | 核心体验 | 技能 |
|---|---|---|
| 面包骑士 | 稳定、抗打、适合新玩家 | 法棍突刺：相邻单体高伤害，并获得列巴护盾。 |
| 黄油射手 | 远程、机动、偏脆 | 黄油箭：射击近处敌人，并滑到旁边空格。 |
| 火腿战士 | 近战清场 | 火腿横扫：攻击相邻全部敌人，并短暂减伤。 |
| 生菜牧师 | 续航和容错 | 生菜祈祷：受伤时治疗，满血时给临时防御。 |

## 数值边界

- 地图缩为 32x22，单局 4 层。
- 前 3 层是探索和成长，第 4 层生成失眠魔王。
- 技能冷却控制在 3-5 回合，避免一键清场。
- 道具保持瞬时使用，不推进敌人回合，降低新手挫败感。
- 技能不是瞬时动作。只有成功生效的技能会消耗玩家回合并触发敌人行动；无目标、条件不满足、冷却中按 Q 都只提示，不推进回合。
- 卷轴道具每层最多 1 个；火腿片从第 3 层开始进入池子，避免背包被单一道具塞满。

## UI 原则

- 游戏中右侧常驻操作说明。
- 背包每个道具显示名称和一句效果说明。
- 日志负责承载荒诞文本，但不阻塞操作。
- 运行时支持静态图和 4x4 sprite sheet。当前 sheet 是程序化占位，后续精美 PNG 动画按 `docs/art/sprite-pipeline.md` 执行。
