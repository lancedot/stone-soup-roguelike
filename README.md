# 面包小队 Roguelike

一个浏览器里的小体量传统 roguelike：随机房间、回合制移动、撞怪攻击、拾取/使用物品、职业技能、升级、永久死亡。第一版目标是 10 分钟以内完成一局，主题是“凌晨两点宿舍段子被正经奇幻套壳”。

凌晨两点，宿舍群里那个离谱段子成真了：有人说睡不着就吃点面包，有人说抹黄油会滑进梦里，还有人坚持火腿和生菜才是安眠配方。笑声刚落，安眠圣域裂开一条缝。面包骑士、黄油射手、火腿战士和生菜牧师被一起卷进地牢，只剩一个目标：打败把全楼都吵醒的失眠魔王，夺回能让人闭眼的安眠圣杯。

## 运行

```bash
npm install
npm run start
```

浏览器打开 Vite 显示的地址，通常是 `http://localhost:5173`。
如果需要开发模式的热更新入口，打开 `http://localhost:5173/dev.html`。

## 操作

- 方向键 / WASD / HJKL：移动；撞到敌人会近战攻击
- Q：使用职业技能；成功才消耗回合，无目标或冷却中只提示
- 数字 1-8：使用背包物品，道具是瞬间动作
- 空格 / `.`：等待一回合
- 走到 `>`：进入下一层
- R：返回选角色界面

## 职业

| 职业 | 定位 | 技能 |
|---|---|---|
| 面包骑士 | 高防近战 | 法棍突刺：重击相邻敌人，并用列巴获得 2 回合减伤。 |
| 黄油射手 | 远程爆发 | 黄油箭：射击距离 6 内敌人，并滑到旁边空格。 |
| 火腿战士 | 近战范围 | 火腿横扫：攻击相邻所有敌人，并获得短暂减伤。 |
| 生菜牧师 | 治疗辅助 | 生菜祈祷：回复生命；满血时获得临时防御。 |

## 内容

- 4 个可选角色：面包骑士、黄油射手、火腿战士、生菜牧师
- 5 种敌人：梦魇老鼠、走廊巡夜灵、食堂甲虫、宿管幻影、失眠魔王
- 6 种道具：热牛奶、生菜叶、硬法棍、厚列巴、黄油块、火腿片
- 卷轴类道具每层最多 1 个；火腿片从第 3 层才会出现，避免前期刷屏
- 4 层短流程：前三层探索和构筑，第 4 层没有继续向下的楼梯，击败 2x2 固定 Boss 失眠魔王获胜
- 角色、普通敌人和职业技能已接入 img2 生成的 4 方向 x 4 帧 PNG sprite sheet
- 地图、道具、Boss 和四个角色通关 CG 已替换为 img2 生成的正式素材；地图地形有 4 套 img2 变体随机拼接

## 开发命令

```bash
npm test                         # 运行核心逻辑测试
node scripts/generate-assets.mjs # 从 art_sources/img2 规范化正式 img2 素材
npm run build                    # 生产构建
node scripts/make-single-html.mjs# 生成可分享单文件 HTML，并把根目录 index.html 更新为 Pages 可直接打开的版本
npm run start                    # 启动开发服务器
```

## 设计原则

- 保留小体量和肉鸽随机性，不扩成完整 DCSS。
- 不做复杂装备槽、任务树、云存档或 Godot 迁移。
- 所有玩家必须能从右侧说明直接理解怎么移动、攻击、使用技能、用道具和获胜。
